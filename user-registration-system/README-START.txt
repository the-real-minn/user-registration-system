# Start this app (Mac + Windows)

Same folder works on both OS. Need **JDK 17+** installed.

## macOS
1. Double-click `Start FIDES.command`
2. To stop: double-click `Stop FIDES.command` (or Ctrl+C in Terminal)

## Windows
1. Double-click `Start FIDES.bat`
2. To stop: double-click `Stop FIDES.bat` (or close the window)

Browser opens at http://localhost:8080

If the JAR is missing, Start will build it automatically (needs internet the first time).
