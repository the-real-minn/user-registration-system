Import FIDES Excel

Upload the FIDES ID Management workbook (.xlsx). The importer reads the User ID sheet and saves FI + credentials into the database.

Expected columns on User ID sheet:

  • A–D: Sr, FI Code, Bank Name, Short Title
  • E–H: VPN (User ID, Password, PSK, Update Date)
  • I–K PSS2 · L–N Inter-Bank · O–Q Mobile Wallet · R–T Fraud · U–W MIB
